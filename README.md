# Технология программирования

Учебные лабораторные работы: интерактивный прототип почтового архива и модульное тестирование пузырьковой сортировки.

## Прототип

Открыть `docs/index.html` в браузере. Доступны поиск писем, карточка, сохранение, настройки и журнал. Ошибку сохранения можно включить в настройках и затем исправить, повторив операцию.

Данные демонстрационные; подключение к почтовому серверу и запись архива на диск не выполняются.

## Сортировка

- `Sorting` — библиотека чтения массива и сортировки.
- `Sorting.Tests` — NUnit: обычные и граничные случаи, параметризация, тестовый двойник чтения.
- `Sorting.App` — оконное приложение для выбора файла и вывода результата.

Требуется .NET 9 SDK, для оконного приложения — Windows.

```powershell
dotnet test Sorting.Tests/Sorting.Tests.csproj
dotnet run --project Sorting.App/Sorting.App.csproj
```

Файл `sample.txt` содержит контрольный ввод. Ожидаемый результат: `-1 0 2 3 3 8`.

BubbleSort изменяет исходный массив, прекращает работу при проходе без обменов. Худшее время — O(n²), дополнительная память — O(1).
